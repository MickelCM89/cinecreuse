# 🎬 CinéCreuse

Application de recommandation de films développée pour le cinéma de la Creuse (France).  
🔗 **[Accéder à l'application](https://cinecreuse.streamlit.app)**

---

## 🚀 Fonctionnalités

- 🔍 Recommandation de films par similarité (moteur TF-IDF avec pondération régionale)
- 🎭 Recherche multi-critères : titre, genre, acteur, réalisateur
- 📊 Tableau de bord KPI : top genres, évolution par décennie
- ❤️ Page Favoris personnalisée
- 🎞️ Enrichissement des données via API TMDB (affiches, synopsis, titres français)
